## 🧠 How It Works

BrainCache is an AI-powered personal memory system that helps you find information based on what you remember, instead of making you search through files and folders manually.

### 🔄 The Workflow

**1. 📥 Add Your Memories**

Upload or add your digital information, such as documents, PDFs, images, notes, and other supported files.

**2. 🤖 AI Analyzes Your Content**

BrainCache uses Google's Gemini AI to analyze supported content, extract useful information, and generate meaningful context that makes your memories easier to retrieve.

**3. 🗂️ Store and Organize**

Your memories can be stored locally for guest use or saved to your personal cloud storage through Firebase, depending on the authentication and storage mode.

**4. 🔍 Search Using Natural Language**

Instead of remembering a filename or folder location, describe what you're looking for in your own words.

For example:
- *"Find the notes where I saved my C programming concepts."*
- *"Show me the document containing my project ideas."*
- *"Find the screenshot related to my previous assignment."*

**5. ✨ Retrieve Relevant Information**

BrainCache uses AI-powered search to help identify relevant memories, making it easier to reconnect with information you've saved.

### ⚙️ Under the Hood

BrainCache combines several technologies to deliver this experience:

- **React + TypeScript** — Builds the user interface.
- **Node.js + Express** — Handles backend API requests.
- **Google Gemini AI** — Powers content analysis and AI-assisted search.
- **Firebase Authentication** — Supports user authentication.
- **Cloud Firestore** — Stores user memories in the cloud.
- **Local Storage** — Supports guest-mode memory storage.
- **File Processing Libraries** — Help extract content from supported document formats.

### 💡 The Core Idea

> **You don't need to remember where you saved something. Just remember what you need.**

BrainCache aims to make personal information easier to access by turning scattered digital content into searchable, meaningful memories.
